# Fonts for the Broker Desk

`manrope-latin-wght-normal.woff2` and `manrope-latin-ext-wght-normal.woff2`:
Manrope, a variable font (weights 200-800), by The Manrope Project Authors,
licensed under the SIL Open Font License 1.1 (`OFL.txt`). Taken from the
npm package `@fontsource-variable/manrope` 5.3.0. Bundled so the desk looks
the same with no internet connection; `tools/desk.py` serves them at
`/fonts/<file>`.
